# RemoteSmith

A two-way remote desktop between a Mac and a Windows PC, built as a thin, renamed fork of
[RustDesk](https://github.com/rustdesk/rustdesk) plus a small tray sidecar. You point it at
your own self-hosted rendezvous/relay server (hbbs/hbbr), or use it on the LAN with no server
at all.

- RemoteSmith ships **no default server**. It never contacts rustdesk.com: no public
  rendezvous server, no API server, no update checks.
- On first launch it asks for your ID server host and public key (or "Direct LAN only") and a
  permanent password of at least 12 characters. The one-time password is disabled.
- Headless setup, on an installed copy, as an administrator:

  ```sh
  RemoteSmith --option custom-rendezvous-server <host[:port]>
  RemoteSmith --option key <contents of id_ed25519.pub>
  RemoteSmith --password <at least 12 characters>
  # or, with no server:
  RemoteSmith --option remotesmith-lan-only Y
  ```

## Layout and building

- `vendor/rustdesk`: upstream RustDesk 1.5.0 as a submodule. RemoteSmith's changes are the
  patches in `patches/`, applied with `scripts/apply-patches.sh`.
- `sidecar/`: the tray app. `deploy/server/`: the hbbs/hbbr deployment.
- Build instructions that reproduce CI: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md) and
  [docs/CI.md](docs/CI.md). The plan is in [docs/PLAN.md](docs/PLAN.md).
